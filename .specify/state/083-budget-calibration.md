### Explicitly unchanged (with reasons)

- **Skill body budget** (`skills/external/improve-skills/scripts/skill-shape.py`, 5000 tokens; 500-line guidance): a deliberate output-size / progressive-disclosure discipline, not a context-window budget. `tests/contract/test_humanize_command_surface.py` (WC-07) explicitly forbids raising it above 5000. Raising it would weaken token efficiency, not unblock 1M-context execution. Not changed.
- **Two-slot test budget** (`efficiency-model.md` §2): a deliberate evidence discipline (one baseline + one closure), not an execution capacity. Not changed.
- **`slot_cap_default: 2` / `slot_cap_ceiling`** (`templates/stage-team-preset.md`): a concurrency-safety budget owned by Feature 064; raising it is a separate concurrency decision, not a threshold recalibration. Not changed.
- **`context_window: 1000000`**: already 1M. Not changed.
