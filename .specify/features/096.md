# Feature Detail: SDD Observer Agent（sdd-observer 专用观察者与线级 journal）

**Feature ID**: 096
**Name**: SDD 专用观察者与线级观察记录（sdd-observer）
**Description**: 每条 driver 驱动的 SDD 线获得一个只观察、不参与的第三方观察者；它以封闭结构把既有载体事实追加写入该 spec 目录的 `journal.md`，只记事件与证据指针，不评价、不建议、不推断；观察者掉线不阻塞开发线。
**Status**: Planned
**Created**: 2026-11-10
**Last Updated**: 2026-11-10

## Overview

本特性新增 `sdd-observer` 角色及其专用实例机制：观察者在线已登记且状态脊已建立之后、首个阶段 U2 派发之前启动，以有界执行窗口运行并允许在阶段边界从同一实例重启，随线终态收束。它不注册写线、不占工作树、不进集成队列；其写面恰为 journal 与自身执行运行产物。

客观性由构造保证：条目是状态脊、runner 正证据四件套、checkpoint、git 历史与执行记录的确定性投影；字段集与事件类封闭；每条条目携带可解析证据指针；唯一确定性引擎（`scripts/python/journal-utils.py`）负责追加与校验。与状态脊 / 汇报义务 / artifact triplet / `/speckit.status` 的边界全部复用既有载体，不新造观测面。

- 计划产物：`plan.md`（22 项宪法全 Pass；5 条 decision-tension；8 条 Execution Premise 全 `verified`；Dependency set: none）+ `research.md`(R-01…R-14) + `data-model.md`(10 实体 / 20 规则) + 5 契约（58 条款）+ `quickstart.md`(8 场景) + 本 `feature-ref.md`（19 交付行、FR/SC 映射、重叠裁定）。
