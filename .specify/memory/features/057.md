**Description**: 补全 agent/team/skills 三个命令面的 run 语义技能化——新增 internal run-skills 与 run-team,接线核查既有命令路由,不新建重复语义技能
**Status**: Implemented

## Overview

推进 goal `command-logic-as-classified-skills`(T-001/T-003:命令核心逻辑由技能承载、命令模板只保留入口与委派)在 agent/team/skills 三个命令面的补全。现状实测:agent 系技能三件套(run-agent/create-agent/improve-agent)已齐,`/speckit.team` 的 run 模式全流程内联在命令模板中,`/speckit.skills` 无 run 语义路由且 modify 族(merge-skills/think-skills)未入路由。本 Feature 新增两个 internal 技能并做接线核查,不新建任何与既有技能语义重复的技能。

## Key Changes

1. run-skills(skills/internal/run-skills):运行未注册技能的统一入口——按工作区位置解析(canonical 优先于 installed 镜像)、已知位置集信任边界、尽力检测注册提示、internal 目标离开 `.specify/` 拒绝执行;自身注册到 agent,是「internal 技能不被 agent 发现」规则的具名例外。
2. run-team(skills/internal/run-team):`/speckit.team` run 模式全流程从命令模板提取,行为平价基线(五查预检/`--target` 不变量/派发治理/报告契约零丢失)。
3. `/speckit.skills` 路由表补齐:modify 族意图行(merge-skills/think-skills)+ run 行(→ run-skills)。
4. `/speckit.agents` 三行路由逐行核查到既有技能,漂移修路由行不修技能。
5. `.specify/skills.md` 指南载明 internal 技能注册例外及多宿主降级路径。

## Implementation Notes

- 两个新技能均带 internal 标注(「技能分类标注」约束侧规则生效;标注必要性主张为用户口述属性,见词汇表该条)。
- run-skills 技能体自足(FR-006):引用真源 + 内联最小操作事实(位置搜索顺序),不复制真源正文。
- run-team 的行为平价对映表(SC-003 证据)是 tasks 阶段产物;落盘后 run 义务真源由 team.md § Run Mode 移交 run-team。
- 身份裁定(2026-10-14):Skill Descriptor 以 canonical 路径为准,镜像副本非独立技能。
