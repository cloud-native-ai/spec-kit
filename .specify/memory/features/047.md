## Key Changes

1. 检查模式(默认):扫描框架自有资料根(运行时动态探测,缺失视为空集),产出分类发现报告并持久化(发现初始 pending),被检材料本体零修改。
2. 过期残留/冗余检测:程序采集确定性证据(提交历史摘要、文件存在性),语义判定只消费证据摘要;证据不足显式标记,不误报。
3. 正确性检查(纯程序判定):死引用、索引↔存储双向一致性、兼容性符号链接有效性、源↔镜像漂移(含孤儿镜像)。
4. 清理执行:按 046 两级判据——删除/归档前置确认清理计划,可逆修复自动执行;处置完成更新发现状态(pending→已处置)并出具三要素执行报告。
5. 职责分诊:属既有命令职责域的发现(docs 收敛→037、链接再生成→008、过程质量→012)以移交建议呈现,不重复实现。
6. 范围红线:不评估、不修改用户源代码/产品脚本/测试用例。
