**Name**: Self-Explanatory Framework Integration（不言自明的框架集成）
**Description**: 把访谈收敛的“不言自明（Self-explanatory）”概念落成框架集成：宪章模板/live 宪章新增原则并指向运行时 owner，instructions 模板/live 文件新增常驻小节，三份 shared owner 文档镜像并随 `specify init` 分发，契约测试与 glossary 条目把集成钉住；客户端指针使用 `.specify/shared/...`，instructions 预算按最小必要幅度上调；`/speckit.improve` 接线登记为 `OI-082-01`，不在本特性。
**Status**: Planned

## Overview

访谈 `/speckit.interview` 已将“不言自明（Self-explanatory）”收敛为三份框架制品：概念定义 `shared/definitions/self-explanatory-definitions.md`、实践指南 `shared/guidelines/self-explanatory.md`、优化工作流 `shared/workflow/best-practice-optimization.md`。本特性只做**框架集成**：让宪章与 instructions 的输出指向这些 owner，让三份文档随镜像与 `specify init` 到达客户项目，并用契约测试把“删掉原则/小节/镜像就会变红”钉住。

关键裁决（详见规格 § Assumptions A1–A11 与 § Clarifications § Session 2026-11-04）：

- **Flow Class = `execution`**（mixed-oracle）：治理文本由读者判，模板生成、镜像一致性与契约测试由机器判；缺陷最先在机器面暴露。
- **绑定新建 Feature 082**：复核 079 双语表述、051 用户可理解性、052 快速失败、029 共享参考目录后均无归属。
- **客户端指针 = 运行时路径** `.specify/shared/definitions/self-explanatory-definitions.md`；框架源 owner 仍是 `shared/...`。模板会被原样复制到客户项目，只有运行时路径可解析。
- **instructions 预算**：live 文件 32,739 B，预算 32,768 B，余量 29 B；新增小节必然超预算，裁决为在新增小节同一变更中按**最小必要幅度**上调 `INSTRUCTIONS_BUDGET_BYTES` 并记录理由。
- **不新建宪章生成器**：宪章由 `manage-constitution` 技能从模板引导；instructions 由 `scripts/bash/generate-instructions.sh` 增量注入。
- **`/speckit.improve` 接线**：登记为 `OI-082-01`，本特性只镜像工作流文档，不接线。

## Implementation Notes

- **Two Hats**：`templates/`、`skills/`、`shared/` 是框架源；`.specify/memory/constitution.md` 与 `.specify/instructions.md` 是本仓运行时输出；`.specify/shared/` 是镜像。MUST NOT 用手改镜像代替源修复。
- **One Source of Truth**：概念 owner 是 `shared/definitions/self-explanatory-definitions.md`；宪章与 instructions 只持有摘要 + 指针，不复制完整定义。
- **测试变异腿**：删除**模板侧**小节后必须直接断言模板/生成器输入缺失；只看 live 文件会让变异空转，因为 live 可能保留旧小节。
- **链接检查**：复用既有 pytest/镜像/链接检查面，不新建独立链接检查引擎。
- **Glossary**：条目按 `origin=auto`、`status=proposed` 登记；旧名“望文生义”只作变体。
- **Out of scope**：`/speckit.improve` 接线（`OI-082-01`）。
