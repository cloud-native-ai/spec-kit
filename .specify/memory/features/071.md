## Overview

`/speckit.review` 目前只做一件事：委派 `review-sdd-process` 评审产生该特性的 SDD 过程，明确不评审代码。另一侧，`code-review` 技能已经是一套完整的代码评审闭环（提交前自检、结构化维度审查、六级严重度、合入门禁、脚本化的 diff/意见/汇总），但**没有任何命令引用它**——维护者跑完 `/speckit.implement` 之后拿不到交付代码 diff 的评审结论，是这个入口最大的缺口。

本特性把两者组合起来，但拒绝把它们混成一个东西：过程段与代码段各自保留判定对象、严重度词汇、产物与证据形态；命令只做编排（固定顺序）与指向。整合后新增的默认风险不是"能力不够"，而是**语义污染**——两套严重度被合成一个评分、代码缺陷被当作框架反馈投递、代码评审被拿来替代表达类的读者基准评审。规格 FR-007、FR-017、FR-027 逐条把这三条污染路径钉死。

边界：不重写历史评审报告、不回填历史特性、不新增 `/speckit.*` 命令、不引入新依赖、不新增 intake 存储或第二套聚合；代码段新增的确定性能力（基准解析、覆盖率回执）落在既有脚本实体上。

## Key Changes

1. **命令编排两段（顺序固定）**：过程段（`review-sdd-process`）无条件在前，代码段（`code-review`）在后；命令模板只做编排、适用性判定与指向，不内联任一技能的方法论。
2. **代码段适用性三取值**：运行 / 不适用 / 不可评估，均为显式记录并附依据或原因；取消"静默跳过"这一第四种形态。
3. **特性切片基准**：代码评审对象 = 本特性已提交代码 delta；基准按"显式 > 本特性 `requirements.md` 首次提交的父提交 > 与默认主干的合并基点"解析，不依赖脚本内置的分支名默认值；工作树改动默认排除并披露。
4. **两套严重度不映射，只声明一条门禁关系**：当前代码段记录含 `blocking` 条目即阻断 `Implemented → Ready for Review`（存在性判定，本特性不定义「清除」动作或「已清除」状态），`important` 要求逐条回应但不阻断；条件写在自称权威的状态机转换表里，其余位置引用它。
5. **覆盖率回执作为"已读全 diff"的唯一证据**：回执的文件集必须等于该次 delta 的变更文件集，逐文件带裁决；缺口以退出码 1 报出、不可评估以退出码 2 报出（字母表闭合为 `0/1/2`），代码段不得给出通过。回执字段块是四项计数的唯一来源，过程报告小节与特性详情条目一律抄自它。
6. **渲染器缺失不再即停，改为降级并标注**：文本模式下照常评审，记录标注渲染模式，且不得声称做过渲染式可视化评审——把"必须用某个工具"换成"不得声称未做的事"。模式选择条件恰为两个：渲染器可用**且**标准输出为 TTY 才渲染，故 agent/非交互调用即便有 `delta` 也走文本模式。
7. **feedback 通道分层**：只有框架自身摩擦可入库，代码缺陷留在代码段记录里；嵌套执行时命令与两个被委派技能（`skill:review-sdd-process`、`skill:code-review`）各自记录，普查为三个单元；063 的建议登记与自省入口、零自动传输等不变量原样保留。
8. **任务/技能边界改写为可判定形态**：两个评审技能各自声明判定对象与"由命令组合"的关系，删除"互不相关"这一在组合后为假的表述。

## Implementation Notes

- 框架源是唯一编辑面（`templates/`、`skills/`、`shared/`、`scripts/`、`docs/`、`tests/`）；`.specify/` 运行时副本与各工具命令副本由既有再生成/镜像同步脚本产出，不手改。
- 既有表达类评审面契约（评审按读者基准判定、MUST NOT 复用代码评审对象）不得被删除或弱化；代码段是**附加**段，表达类特性无代码 delta 时记不适用。（FR-027）
- probe 注册面本特性预期不改（review 与 code-review 的收尾面均已注册）；若落地时确有注册变更，先重编译再同步，不手改编译面。
- 已观察到的既有事实重复：`Implemented → Ready for Review` 的判据措辞在状态机转换表与特性集成协议中各有一份且措辞不一致；本特性把后者收敛为对前者的引用（FR-008），属"把复制改成引用"而非"把措辞改到一致"。
- 编号与脚手架：编号由项目脚本派生（071）；脚本的 `git checkout -b` 被抑制（无人值守阶段规则禁止阶段子代理切换分支），规格目录与初始文件仍由该脚本产出。
- 范围排除：不重写历史评审报告、不回填历史特性、不新增 `/speckit.*` 命令、不引入新依赖。
