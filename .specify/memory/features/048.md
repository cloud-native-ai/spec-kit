# Feature Detail: Browser Utils Skill

**Feature ID**: 048  
**Name**: Browser Utils Skill  
**Description**: 浏览器自动化与 Web 应用测试能力:能力三分层(Tier 1 内置浏览器 / Tier 2 脚本自动化 / Tier 3 MCP 连接器)、脚本自动化双方向(页面级模拟 / 请求级调用)、按 domain 键控的站点记忆与四态生命周期(探索期/优化期/验证期/sealed)。  
**Status**: Implemented

## Overview

browser-utils 是 Spec Kit 的浏览器自动化技能。本 Feature 承载其能力本体建设:纯能力导向的三层策略路由(不绑定具体 agent 产品)、页面级与请求级两个自动化方向、以及按站点(domain)累积操作记忆的机制——首次探索留痕、二次蒸馏请求级步骤、三次验证固化(sealed),使同一站点的重复自动化从逐步摸索进化为固化流程直接执行。
