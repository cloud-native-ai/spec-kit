# 094 — Goal/Team Parallel（目标/施工队 × spec 并行）

## Overview

085 把 goal/team 当作「临时」对象：定义住在 spec 目录里、生命周期挂在一次 spec 上、默认是 SDD 的下位物。
本特性重定义绑定关系并把档案收拢到一处：**goal** 是设计师画的目标，**team** 是施工队；两者与 spec 是
**三向绑定**（`goal_slug` / `team_slug` / `handoff_ref`），不是父子。目标是让 goal 线、team 线与 SDD 线三条线
可以真正并行：任何一条都不要求另一条先存在，复杂 spec 用一份交接契约（`handoff.md`）把目标转给施工队，
施工队只能写自己的 territory 并逐任务回执。

上游 2026-11-09 已把全局 goal 档案目录从 `.specify/goal/` 改名为 `.specify/anchoring/`（定义文件名仍
`goal.md`）；本特性按该实况重述路径词汇（D4），并把「临时/全局」从分类判据改为由 binding 回答的归属。
