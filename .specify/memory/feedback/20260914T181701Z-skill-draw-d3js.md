cycle-3 arena 复刻任务: 以 PIL 连通域像素量测 target.png 得到面板/节点盒/箭头端点/dash 周期/stroke 宽度, 单文件 HTML 内联 D3 v7.9.0 固定坐标渲染, headless Chrome 截图与目标做连通域 diff 迭代收敛 (19 组件盒 ±1px, 深色像素 96-97% 在 ±2px 内匹配); 交付含导出按钮/复现附录/tooltip/?clean 快照开关。过程干净, 无返工缺陷。

## Optimization Points
- 复刻类任务（target image → D3 图）建议固化为技能食谱：PIL 连通域量测（box/panel/arrow 端点/dash 周期/stroke 覆盖率→stroke-width）+ headless Chrome 截图 + 连通域 diff 的闭环迭代；本次 19 个组件盒全部 ±1px 命中，纯目测坐标做不到。
- headless Chrome（macOS new headless）`--window-size=W,H` 的布局视口高度约 H-87px，等高截图会裁掉 SVG 底部；验证截图应加高窗口再裁剪，或在 CSS 用 `width: min(100vw, <ratio>vh)` 让矮视口 letterbox 而非裁切（本次两者皆用）。
- 源图为单色/无边标签时，技能 checklist 的「图例色块」「边标签常显开关」条目应显式标注 N/A 并说明由面板标题承载分组语义，避免为凑清单而偏离源图忠实度。
