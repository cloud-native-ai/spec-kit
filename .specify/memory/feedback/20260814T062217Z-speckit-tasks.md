## Optimization Points
- **Story 间硬链与"迁移不返工"的设计应前置声明**:US1→US2→US3 是硬依赖,而 US5 的物理迁移(7 角色定义换位)按常理会击穿 US3 的集成测试;本轮靠"测试计数用 len(glob) 派生 + 断言对象参数化"让 US3 测试对迁移免疫,这是一个跨 phase 的隐式设计决策。它现在只散落在 T018/T026 的措辞里,Dependencies 节一句话带过。建议 tasks 模板在 Dependencies 节加一个"返工免疫设计"小栏:凡后续 phase 的物理变更可能击穿前序 phase 测试的,必须显式记录免疫手段,否则 /speckit.implement 按拓扑执行时会撞上意外红灯。
