## Optimization Points

- 2. **团队 run report 与 summary 机器的形状断层**:三份 `*-report.md` 均无 `**Outcome**` 字段与可解析的 `## Deliverables` 表,summary 生成器把每个 run 折叠成状态 unknown 的单工作项(FR-027 降级)——run report 约定(本命令模板 §7 的固定字段)与 summary-mapping 的消费面从未对齐;本轮 summary 的 milestones 因此全部 `unknown-schedule`。建议:在 team.md 的报告约定或 summary-mapping 一侧声明最小字段集(Outcome + Deliverables),让折叠不再全靠降级。
- 3. (轻微)**run report 状态行的写入时序**:本 run 报告的 `Summary: produced` 是预期值先行、summary 步骤回看才发现——状态行应由产生事实的子步骤回填,报告模板宜注明该行的合法写入时点。
