- plan 模板的 Mirror Obligations 表默认让人写「sync-mirrors --check exit 0」式判据,但仓内存在长期既有镜像漂移(本轮实测 git-fleet 缺 6 个 .specify/skills/ 镜像,exit 2),笼统写 exit 0 即写下一条不可能通过的判据;建议模板在该表加一行提示:镜像判据须先实测当前 --check 结果,再按「所触及镜像对无新增漂移」表述,与 Recurring Operational Lessons 里的测试基线纪律对齐
