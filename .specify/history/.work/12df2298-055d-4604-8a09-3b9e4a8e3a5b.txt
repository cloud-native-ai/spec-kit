## `/speckit.agents` 命令的系统行为

执行 `/speckit.agents` 时，系统加载 `.claude/commands/speckit.agents.md` 作为 prompt 指令注入到对话中，指导 AI 完成 agent 创建工作。具体行为取决于是否携带参数：

### 两种执行模式

**源模板** (`templates/commands/agents.md`) 定义了双模式，但 **Claude Code 安装版** (`.claude/commands/speckit.agents.md`) 只保留了单模式（自定义创建）：

| 版本 | 无参数 | 有参数 |
|------|--------|--------|
| 源模板 | Mode A: 批量生成6个角色 agent | Mode B: 创建自定义 agent |
| Claude 安装版 | 从对话/仓库上下文推断意图 | 按用户意图创建自定义 agent |

### 核心执行流程（Claude 版本）

1. **解析 `$ARGUMENTS`** — 将用户输入作为 agent 意图参数
2. **工作区脚手架** — 首次运行时创建 `AGENTS.md`、`MEMORY.md`、`SOUL.md`、`USER.md`
3. **从对话提取上下文** — 审查会话历史，提取角色/工具偏好/领域范围
4. **分类 agent 类型** — 必须归类为 `Knowledge` / `Plan` / `Research` / `Common` 之一
5. **向用户确认类型** — 展示分类结果和模板路径，等待确认
6. **选择模板** — 按类型加载 `.specify/templates/agent-<type>-template.md`
7. **定义 agent 形状** — 确定文件名、工具集、调用模式等
8. **迭代生成** — 草稿 → 保存 → 提问改进 → 最终确认
9. **写入文件** — 保存到 `.specify/agents/<name>.agent.md`（规范路径）
10. **注册到 Resource Registry** — 更新 `.specify/instructions.md` 中的 Agents 表
11. **验证符号链接** — 确认 `.github/agents/` 等目录链接到 `.specify/agents/`
12. **报告** — 输出路径、agent_id、示例 prompt、后续建议

### 关键约束

- 只写入 `.specify/agents/`，工具目录通过 symlink 发现
- 最小权限工具集（默认 `["read", "search"]`）
- 仅支持 Claude Code / Copilot / Qwen / opencode / Qoder 五个 provider
- YAML 校验不通过则阻止保存
- 完成后建议执行 `/speckit.instructions` 刷新发现元数据

### 源模板额外的 Mode A（批量生成）

源模板在无参数时会从 `templates/agent-role-*-template.md` 批量生成6个预定义角色 agent（Requirements Analyst、System Designer、Module Designer、Test Engineer、QA Engineer、Knowledge Manager），并用项目上下文填充占位符。这部分在 Claude 安装版中被裁剪掉了。
