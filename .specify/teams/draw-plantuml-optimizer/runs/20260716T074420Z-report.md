## Lessons
1. 文字修饰是独立一步：标题(简洁·在元素上) 与 详解(清晰·外置 note) 分工。
2. 外置 note 布局安全是硬约束：顶层/贴白空可靠；深层嵌套成员常被甩到页边→省略/折叠父级/legend。
3. 相邻 note 比远处 legend 更易懂含义，但 legend 仍是布局不安全时的兜底。
