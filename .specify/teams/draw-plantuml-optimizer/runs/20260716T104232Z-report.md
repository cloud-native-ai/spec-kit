## 方法
清空 109 个已生成 `.puml`/`.svg`/`.png`；技能冻结为 target；同一 benchmark（图2 部署&治理）从零独立重绘多次，同一 rubric 评分，测方差。

## 结果
- **首轮 3 次（暴露不稳定）**：分数 0.88 / 0.83 / 0.80（极差 0.08）；宽高比 1.41 / 2.8 / 1.70；彩色 是 / 是 / **否**。
- **根因**：
  1. 渲染管线对 UML 强制 `skinparam monochrome true`，仅当源含 `<color:>` 标记才跳过 → 保色不确定（round3 变灰）。
  2. §4e 宽高比预算不够机械 → 底带排成一长行 → 2.8 宽。
- **修复（确定化，已入技能，3 副本同步）**：
  - §2 **保色配方**：源放 `skinparam monochrome false` + legend 至少一处 `<color:#..>`，输入/输出异名。
  - §4e **每行 ≤5 否则折 2×N 网格、严禁一长行**（列数 ≈ round(sqrt(节点数))）。
  - §4b.6 **`skinparam linetype ortho` 在嵌套 cluster + 指向 cluster 节点的边上会确定性崩 GraphViz** → 边只连叶子 / 回退默认 spline。
- **复测 3 次（验证）**：分数 0.90 / 0.89 / 0.89（极差 ~0.01）；宽高比 1.42 / 1.26 / 1.24（全 ~4:3）；彩色 **是 / 是 / 是**。

## 结论
技能现在**稳定**产生符合要求的部署图：分数极差 0.08 → ~0.01，彩色 2/3 → 3/3，宽高比全部落入 4:3 附近。稳定性靠「把随机分叉点确定化」（保色配方 + 机械换行 + 崩溃回退）实现——**不确定的自由度是稳定性的敌人**。
