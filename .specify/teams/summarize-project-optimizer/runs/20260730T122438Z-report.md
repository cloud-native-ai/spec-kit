## 采纳的关键改进

**人员维度从「被静默丢弃的采集字段」变成一等图元**（三个评分器 Gen-1 一致指出的最大缺口）：
- 三层强制承载位：记录层负责人列必填 → 图内标注（WBS `【姓名】` 第二行 / 甘特条形后缀 / 里程碑标签 `▪负责人`）→ 报告固定的 `### 人员与分工` 小节，首句必须是覆盖率声明
- 数据缺失时的显式声明位（`未记录` / 图内 `caption` 声明），禁止静默省略；git 三级推断回退规则

**图表编码规范化**（Gen-1 visual 的核心贡献）：
- 统一三态色板（精确 hex，跨图同色、图例同字面量）+ 冗余符号列
- WBS 编码 任务×人员×状态×`◆Mn` 里程碑锚点；甘特再叠加日期轴 + 条内完成比例 + today 参照线 —— 五维同图编码
- 里程碑菱形强制带 `yyyy-mm-dd` + `✓/◇/⚠` 三态 + 机械逾期判定（锚定日 < 基准日且未达成 ⇒ at-risk）
- 图例零实例退化契约（含确定性比对脚本）；里程碑视图独立成图判定规则
- 渲染契约：成功三判据、≤2 轮修正、失败必须 `> ⚠` 告示 + 元信息渲染状态清单

**记录层数据结构**（Gen-1 content 交叉合入）：四结构 schema（目标块 / 任务记录表 / 里程碑记录表 / 人员映射表）+ 日期 `yyyy-mm-dd` 归一化 + 溯源列 + 派生完整性检查。
