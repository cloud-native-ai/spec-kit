## Change

- Before: the `receipt` subcommand summed `git diff --numstat` over every changed file and
  refused with exit 2 as soon as a binary line (`-\t-\t<path>`) appeared — even when a legal
  `--skip-with-reason <glob> --reason binary` selector named that path. The skill declares
  `binary` a legal skip reason (FR-014 closed set), so the selector was unusable.
- After: the skip selectors are applied **before** the line-count loop. A matched path is
  excluded from `lines_added` / `lines_deleted` and never triggers the binary refusal; an
  unmatched binary file still refuses with exit 2 (C-41 / V16 unchanged).
  Implementation: `skills/internal/code-review/scripts/git-delta-review.sh` (§ receipt,
  the numstat loop) — one loop guard, no other semantic change.
