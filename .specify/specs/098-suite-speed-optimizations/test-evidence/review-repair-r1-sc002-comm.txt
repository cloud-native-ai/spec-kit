# SC-002 bidirectional comparison — review-repair r1 (final tree, tests/contract)
# Date: 2026-11-11; same tree for both arms; same runner form; tier=fast excluded_slow=5.

## Root cause repaired (I2/A2)

- `tests/contract/test_trigger_engine.py::run_cli` spawned the engine without an explicit
  workspace. The engine's contract C-7 gives **engine self-location** priority over the CWD
  walk; this worktree lives under the parent repo's `.specify/.tmp/`, so every call resolved
  to the parent repository instead of the pytest fixture. Two fail shapes followed: the
  shared trigger store accumulated session state across runs, and concurrent workers raced
  on one `index.json` — the observed serial-only names were the ones that flipped between
  arms.
- Repair (isolation-defect path of C-004): `run_cli` passes `--workspace <cwd>` unless the
  call already names one (the C-7 priority then resolves the fixture; C-7 keeps explicit
  `--workspace` first, so the engine contract is untouched). The file then runs 145/145
  green under the canonical runner (7.46 s, `mode=parallel workers=auto`).
