# In-process conversion — mutation drills IC-M1…IC-M5 (T054)

Feature: 098-suite-speed-optimizations (US5). Contract:
`contracts/inprocess-conversion.contract.md` § D. Carrier: `test-evidence/inprocess-conversion.md`.

Execution model: each drill is applied to a **throwaway copy** — a `git clone --shared` of
the worktree at HEAD with the WP-8 working-tree diff applied (`.specify/.tmp/wp8/mutant/`,
git-ignored scratch). The tracked file is restored after each drill; a final guard run
confirms the restored copy is green. The real worktree is never mutated.

| Leg | Mutation | Guard case that must fail | Observed |
|-----|----------|---------------------------|----------|
| IC-M1 | one converted call returned to `subprocess.run` | C-007 revert detection | FAIL (exit 1), site named |
| IC-M2 | one manifest row deleted for a discovered site | C-006 completeness | FAIL (exit 1), site named |
| IC-M3 | one `keep` row given a class outside the closed set | C-002 closed set | FAIL (exit 1), row named |
| IC-M4 | one converted helper rewritten as an import-only check | C-008 route-preservation leg | FAIL (exit 1), row named |
| IC-M5 | one `--help` case converted while its keep row stays | C-002/C-010 keep-side sample | FAIL (exit 1), stale keep row named |

Guard command for every leg:
`bash scripts/bash/run-tests.sh --workers 2 tests/contract/test_inprocess_conversion_contract.py -q`
