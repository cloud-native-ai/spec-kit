## 5. Attempt 1 (superseded diagnostic) and the isolation repair

- Attempt 1 (pre-repair tree): parallel exit `1`, wall **71.82 s**, `254 failed, 8332 passed,
  2 skipped, 576 warnings in 48.22s`, 254 names
  (`test-evidence/closure-prerepair-parallel-failed.txt`, sha256 `9d01ba48…13cedaa`);
  serial exit `1`, wall **717.18 s**, `249 failed, 8338 passed, 2 skipped, 3 warnings in 715.03s`,
  249 names (`test-evidence/closure-prerepair-serial-failed.txt`, sha256 `6dd88969…e717db5`).
  `comm -13` = 0; `comm -23` = **5** — five parallel-only names, all
  `tests/integration/test_trigger_tuning.py`.
- Root cause (measured, not guessed): the engine's C-7 resolution order is
  `--workspace` > engine self-location > nearest `.specify` CWD ancestor > CWD. This worktree is
  nested under the parent repository's `.specify/.tmp/`, so engine self-location wins and resolves
  to the **parent repo**. Probe (read-only `status` action from a scratch cwd):
  `workspaceRoot=/storage/project/cloud-native-ai/spec-kit`. The tuning and promotion helpers ran
  the engine without `--workspace`, so the tests shared the parent repo's trigger store: the 18
  promotion tests read a fixture `index.json` that was never written (`FileNotFoundError`) and the
  tuning tests raced on shared state under xdist (parallel-only names).
- Repair (C-004's isolation-defect path; the same repair review-repair r1 applied to
  `tests/contract/test_trigger_engine.py`): pass `--workspace <cwd>` unless the call already
  names one. Files: `tests/integration/test_trigger_tuning.py`,
  `tests/integration/test_trigger_promotion.py`. No assertion was weakened, no test removed or
  narrowed, no skip/xfail/retry introduced (the SC-010 forbidden-means set).
- Targeted green: `bash scripts/bash/run-tests.sh --workers 8 <both files> -q` → exit 0,
  `38 passed in 3.46s`; `bash scripts/bash/run-tests.sh --serial <both files> -q` → exit 0,
  `38 passed in 16.74s` (`test-evidence/closure-isolation-fix.txt`).
- Slot 2 was then re-taken on the repaired tree (sections 1–3). Attempt 1's readings are retained
  above as the diagnostic that found the defect; they are not used as any SC-004/SC-005 wall.
