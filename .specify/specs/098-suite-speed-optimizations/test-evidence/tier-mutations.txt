## Method notes

- Tier legs use a minimal harness copy (runner + script-interface.sh + the guard file +
  a pytest.ini registering `serial`/`slow`/`contract`); every case is selected by exact
  node id, so a `-k` substring can never pull an unrelated case into a leg.
- Slow legs and TS-M8 use a full-tree copy (135 MB; `.git`, `.specify/.tmp`,
  `__pycache__`, `.pytest_cache` excluded), one copy per drift.
- Obligation 11's baseline carries two parametrized ids whose bracket embeds the absolute
  tree root (T022 normalized them to the worktree root). A full-tree copy at any other
  path re-normalizes exactly those two ids to the copy root before drilling — an
  adaptation of the baseline *input* for the copy, not a mutation of the guard; the
  tracked baseline is untouched, and the real-tree obligation 11 is green (control below).
  Without that adaptation the pristine copy reddens on those two ids alone (observed
  once; not a membership signal).
