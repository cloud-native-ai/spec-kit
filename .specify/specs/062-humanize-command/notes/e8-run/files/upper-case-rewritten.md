每天凌晨 2 点，调度器自动触发对账作业，作业 ID 为 `recon-daily-2am`。流程两步：先拉取清结算平台的日切文件（命名规则 `settle-YYYYMMDD.csv`），再与订单库当日流水逐笔比对。差异笔数超过 50 笔时作业自动转人工，差异清单写入按日期命名的文件（如 /var/log/recon/diff-20261019.csv 这类路径）。

过去 30 天，对账差异率一直稳定在 0.03% 以下。9 月出现过一次 1.2% 的异常尖峰：清结算侧重发了日切文件，同一交易日产生两份内容不同的文件。上游随后在文件名中加入序号后缀（`settle-20260918-002.csv`），问题才闭环。
