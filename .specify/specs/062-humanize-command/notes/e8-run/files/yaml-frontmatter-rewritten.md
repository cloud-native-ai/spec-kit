每天凌晨 2 点，调度器自动跑一次对账作业，作业 ID 是 `recon-daily-2am`。流程分两步：先从清结算平台拉取日切文件，文件名形如 `settle-YYYYMMDD.csv`；再与订单库的当日流水逐笔核对。差异超过 50 笔时，作业自动转人工处理，差异清单会写入一个按日期命名的文件（如 /var/log/recon/diff-20261019.csv）。

最近 30 天，对账差异率一直稳定在 0.03% 以下。唯一的异常发生在 9 月：差异率一度冲到 1.2%。根因是清结算侧重发了日切文件——同一个交易日出现了两份内容不同的文件。上游随后在文件名里加了序号后缀（`settle-20260918-002.csv`），问题才彻底闭环。
