# 客户支持本季度运营情况（面向非技术管理者）

这个季度，客户支持的工作量和工作速度都有改善。工单总量 12,480 件，比上季度少了 6.2%——可以理解为：客户每提一次需要帮忙的请求就算一件工单，总量少了，说明很多问题没有发展到要找人工的地步。客户从提问到第一次得到回应，平均要等 1.9 小时，比上季度缩短了 0.7 小时——等待时间变短，客户的体验会更顺。

有一项指标需要如实说明：本季度流失掉的客户占总客户数的 4.8%，比上季度多了 0.9 个百分点。我们对 12 家流失客户做了访谈，其中 7 家明确提到：等待回应的时间还是太长。换句话说，响应速度仍是客户离开的主要原因之一。

也有进展：越来越多客户不用等人工，自己在知识库里就找到了答案——这部分「自助解决率」达到了 58%，主要功劳是本季度新上线的知识库推荐模块。客服团队本月新增 4 人，都还在培训期，完全上手还需要一些时间。
