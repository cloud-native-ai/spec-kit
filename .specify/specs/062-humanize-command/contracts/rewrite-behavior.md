# Contract: 四维度改写行为与保真（rewrite-behavior）

**Feature**: 062 | **FR 覆盖**: FR-002 至 FR-013, FR-026（以文末可追溯性表为准）
**性质**: 行为契约——技能承载的改写行为义务。行为验证主通道为 E8 评估协议（语料 + 量规 + 两位独立评审 + 确定性差异脚本）；结构面由契约测试钉扎（技能体对应指令落点存在）。

## 四维度完整性

- **C-11**: 每次改写完整应用四个维度，技能体的工作流不含「按需跳过某维度」的分支；维度适用性由维度自身义务界定（如纯文本输入的格式维度按其形态执行），而非由 agent 自由裁量省略。FR-002 的「不得静默省略」由此承载（FR-002）。
- **C-12**: 语气与风格自然化维度：删除或明显减少公式化 AI 套话、重复句式与机械/冷漠/不必要的绝对化表达，使文本读起来像有经验的真人作者所写（FR-003）。
- **C-13**: 上下文与逻辑补全维度的边界：补充的过渡、背景与解释 MUST 限于输入已蕴含或严格可推出的范围；MAY 将已有抽象表述具体化；MUST NOT 引入原文没有的事实、例子、统计数字、来源或因果断言（FR-004）。
- **C-14**: 格式与可读性维度：拆分密集段落，使用标题、列表、强调与留白提升可读性；输入含核心结论且前置不改变含义时将结论前置；不为追求简短删除实质性内容（FR-005）。
- **C-15**: 降低 AI 痕迹维度：通过词汇多样性、句式与句长变化、去除公式化模式降低机器感；不承诺、不暗示、不专门优化「通过任何 AI 内容检测器」；本维度服从 C-16 保真底线（FR-006）。

## 保真与受保护内容

- **C-16**: 保真底线：全部事实、数字、单位、日期、名称、结论、因果关系与引用关系保持不变；不编造事实、例子、统计数字、来源、链接或署名；遇歧义保留原状，不通过编造消除歧义。此条款为全契约最高优先级行为约束，与任何其他条款冲突时保真优先（FR-007）。
- **C-17**: 受保护内容逐字保留或语义完全等价：引文、代码块与行内代码、命令、文件路径、URL、标识符、公式、YAML/TOML frontmatter 与表格数据；其外围格式可调整，内容不可改变（FR-008）。
- **C-18**: 最小改动：对已自然的文本不降低质量；无实质性改进依据时至多轻微润色，并明确说明没有需要实质修改的内容；不为显示工作量而改动（FR-009）。
- **C-19**: 矛盾与未决信息：输入含互相矛盾或未解决的陈述时全部保留并向调用者报告冲突；不用编造的统一结论掩盖冲突（FR-010）。
- **C-20**: 完整性：处理全部输入内容，不静默截断、不以摘要替代正文、不跳过内容；执行限制导致无法完成时报告未处理部分；部分结果 MUST NOT 呈现为完整结果；长文档分段处理必须重组为单一连贯结果，章节无重复无遗漏（FR-011, FR-023, SC-006）。

## 输出与语言

- **C-21**: 完整改写文本是主要输出；可附简短变更说明，但改写文本本身可独立阅读；差异列表、提纲或修改说明不得替代正文（FR-012）。
- **C-22**: 语言保持：输出使用输入主语言（中文输入输出中文、英文输入输出英文、混合按主语言）；技术术语、专有名词与代码标识符原样保留；翻译不在范围内（FR-013, SC-003）。
- **C-23**: 行为评估协议（FR-026 行为面的证据通道）：以 E8 固定语料执行评估——两位独立评审按 `rubric.md` 量规独立判定（适用维度失败即样本失败）；受保护内容由确定性差异脚本逐项比对（改变数为 0、编造数为 0）；语言矩阵、语气矩阵、文件行为与长文档场景各按其 SC 的测量源执行；评估记录落 verification.md。本条款不指定评审人选与评分工具，量规为唯一判定标准（FR-026, SC-001, SC-002, SC-003, SC-004, SC-006）。
