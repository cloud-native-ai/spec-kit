# Contract: 语气、输入解析与文件行为（tone-input-file）

**Feature**: 062 | **FR 覆盖**: FR-014 至 FR-023, FR-028（以文末可追溯性表为准）
**性质**: 行为契约——技能承载的输入解析、语气处理与文件安全义务。结构面由契约测试钉扎；行为面由 E8 语料中的文件行为测试与语气矩阵承载。

## 语气与受众

- **C-24**: 未指定语气时使用缺省语气 `professional`——专业、自然、面向一般读者，不注入强烈个性或情绪；缺省语义在技能体有明确指令落点（FR-014, SC-004）。
- **C-25**: 技能接受封闭语气集合 [[STR-002]] 与自由文本受众描述；语气与受众只调整词汇、句式节奏、解释深度与例子选择，即只作用于表达层（FR-015）。
- **C-26**: 语气与受众 MUST NOT 覆盖保真底线：所请求语气会要求改变事实、结论或造成误导性强调时，保留保真所需的表达并向调用者报告该限制（FR-016）。
- **C-27**: 调用者给出集合外语气值时，报告该值与支持集合；不静默替换为另一种语气，不声称已应用所请求的语气（FR-017）。

## 输入解析与拒收

- **C-28**: 每次调用恰接受一个输入源：内联内容或一个文件路径。两者同给 → 拒绝并说明「一次只接受一个输入源」；多文件或目录路径 → 同一拒收面（首版不支持批量处理）；内联内容为空或仅含空白字符 → 拒绝，不产生任何输出文件（FR-018）。
- **C-29**: 文件输入支持格式 [[STR-003]]；路径必须解析为可读普通文件；路径不存在、指向目录、扩展名不受支持、内容为二进制/非文本或文件为空时，以清晰消息拒绝并指出问题与支持格式；不输出乱码文本（FR-019）。

## 文件安全默认

- **C-30**: 未显式给出输出路径时不创建、不修改任何文件；不写隐式同目录副本；不原地覆盖输入文件（输出路径 == 输入路径 → 拒绝，首版显式排除）（FR-020）。
- **C-31**: 显式输出路径行为：目标不存在且父目录可写 → 写入完整改写文本并报告写入位置；目标已存在且未获显式覆盖确认 → 拒绝覆盖、目标文件逐字节不变、报告冲突；写入失败（父目录缺失、权限不足等）→ 报告失败、不声称成功、已有目标文件保持不变（FR-021, SC-005）。
- **C-32**: 输出格式跟随输入格式：Markdown 输入产出 Markdown，纯文本输入产出不含 Markdown 专有语法的纯文本；写文件时保持对应格式（FR-022）。
- **C-33**: Markdown 文件的 YAML frontmatter 逐字保留，仅正文进入改写；frontmatter 中的键值不因正文改写而变化（边界场景的义务面；FR-008 的文件级实例）。
- **C-34**: 敏感与机密内容：不发起任何外部传输；改写只在执行该命令的 agent 上下文内完成——本条款是 FR-028 在调用者数据上的实例化（FR-028）。
