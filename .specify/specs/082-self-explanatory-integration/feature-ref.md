## Disclosed rulings (this stage)

1. **Live constitution numeral is not pinned.** The template roster is 17 and the live roster 18 at plan
   time; the same title lands at each surface's next free numeral. No test, clause, or row states a
   numeral value (C-3).
2. **Two surfaces carry `STR-001` verbatim.** Rationale, antithesis and the drift guard are recorded as
   decision tension `T-002`; the duplication is deliberate and paid for by C-12 (set membership on both
   surfaces) rather than by renaming one surface.
3. **The budget raise is computed, not chosen.** Smallest multiple of 1024 leaving at least 1024 B of
   headroom, with the old/new/reason recorded in the commit body (C-17, C-18, plan T-001). The plan does
   not state the post-raise number, because the plan cannot measure a file that does not exist yet.
4. **The gate-scanner total drift is pre-existing and out of scope.** Live 27 vs frozen 23 (plan EP-003,
   `Decision: fallback`). This feature writes zero blocking-pattern hits and does not touch the frozen
   baseline; every stage's targeted-run evidence must name
   `tests/contract/test_proactive_trigger_section.py::test_c11_gate_scan_total_unchanged` as a
   pre-existing red rather than report "clean".
5. **The mirror obligation is `keep`, not `reach`.** The stage measured exit 2 then exit 0 for
   `sync-mirrors.py --check`; the three mirrors now exist and `cmp` identical (research.md B-1, B-7).
   The plan discloses that the plan stage issued no `--write`, so the criterion is "no new `MISS`/`DIFF`
   line on the pairs this spec touches", and requires re-measurement before any claim.
6. **`/speckit.improve` wiring is out of scope** (`OI-082-01`). C-28 forbids reading "document mirrored"
   as "command wired" and asserts `templates/commands/improve.md` stays untouched by this feature.
7. **Distribution was executed against the published CLI and correctly found nothing.** `specify init`
   in a fresh directory creates the `shared/` sink but the three documents are absent because the
   installed release predates them; the run confirms the copy path works and the sink exists
   (quickstart S-1/S-6). The Feature's own acceptance must use a release carrying the documents.
