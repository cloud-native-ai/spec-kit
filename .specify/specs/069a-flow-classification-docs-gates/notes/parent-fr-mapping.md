## Numbering Rule

- **切片内连续编号**：切片正文使用自己的连续 ID 空间（FR-001–FR-027、SC-001–SC-008）。`validate-requirements.py` 的 `id-contiguous` 把任何编号缺口判为「行被删除或从未写」，父编号区间在切片内必然留缺口，因此切片不沿用父编号。
- **父映射表**：切片 ID → 父 ID → 主题的对应只在本文件与切片正文的来源说明中出现；切片正文的交叉引用一律使用切片本地 ID。
- **父仍是权威**：父 `requirements.md` 的 41 条 FR / 13 条 SC 定义未被修改，仍是唯一规范来源；切片编号只是对父条目的投影。
- **不是删除/合并/重排**：编号变化不改变任何要求的语义、范围、SC 取值或验收标准，不构成对父条目的删除、合并或重排；父规格中的编号区间不变。
