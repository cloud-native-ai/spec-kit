FR-027 的判定单位是 `git diff` 的**新增行**，不是整棵树的命中数：树里已有的 27 处阻断式门是

## 对 implement 阶段的传导
- 判据：`git diff 35ff11bc` 的新增行与 BLOCKING_PATTERNS 的交集 MUST 为 0（不是「整树 27 变 27」）。
- 硬约束（实测同一条正则）：新增文案 MUST NOT 使用英文短语 `confirmation gate`、`after
  confirmation`、`Confirm before`、`stop and confirm`，也 MUST NOT 使用「确认门禁」「确认门控」。
  描述既有确认行为时用「该动作自身的确认步骤 / 未获答复」等不含上述字面量的表达。
- 复核命令与本节第 2 段同形；命中即 FR-027 失败，不得以「命中行属于既有资产」豁免
  （新增行全部是本特性写的）。
