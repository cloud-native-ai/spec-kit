## 判据可判定性

**C-10** `## 分流判据` 节 MUST 含:(a) 机械测试字面量 [[STR-005]] 恰好一次;(b) 二值枚举(顺手修复 / 快速失败)且 MUST NOT 出现第三值或"尽量少停"一类不可判定表述;(c) 四条必要条件的完整枚举;(d) FR-070 的裁决顺序声明(**判据优先于清单命中**);(e) 存疑从严默认;(f) FR-013 的**上送极优先**裁决顺序——文本 MUST 声明一处异常同时命中两份清单时按快速失败处理,该项与 (d) 不是同一条顺序((d) 裁「判据 vs 清单命中」,(f) 裁「两份清单互相命中」),故 MUST 各自可独立定位;(g) FR-014 的**两振升级**规则——文本 MUST 声明同一异常在一次运行内第二次出现即升级为快速失败、MUST NOT 再按顺手修复处理,且 MUST 以**复发键 = `被证伪的预期` 单键**指称"同一"的认定依据,并 MUST 显式声明该键**不含发现点**(键的拥有者是 `data-model.md` 的异常实体 E2;2026-09-23 用户裁定)。"不含发现点"这一负面声明本身 MUST 被断言:它是本次裁定的**唯一没有其它机械守卫的回归路径**——若日后把复发键与 FR-044 的独立键 `(发现点, 被证伪的预期)` 合并回单键,FR-014 会在跨发现点复发时静默变为不可达,而单纯的字符串在场断言不会变红。

**C-11** `## 分流判据` 节 MUST 含 `爆炸半径` 的**可判定定义**:定义文本 MUST 出现"当前动作"与"声明的范围"(或等价表述),使该判定为集合包含判定而非形容词。未定义即红——FR-010(d) 是必要条件之一,而 SC-001 要求双评审者 100% 一致。

**C-12** `## 分流判据` 节 MUST 含机械测试字面量 [[STR-006]] 恰好一次,且 MUST 以路径援引两条既有配套手法(变异演练、反空真哨兵)所在的教训小节,MUST NOT 复述其正文(FR-015 / FR-021)。

## 两份清单

**C-13** 两份清单 MUST 各自:(a) 非空;(b) 每行匹配 `^- \*\*(FF|RP)-\d+ `;(c) 每行含 `判据:` 分隔符;(d) 声明封闭性(扩展 MUST 只经修订本文档)。

**C-14** FR-016 点名的 **7 项**已实测失效形态 MUST 在 fast fail 清单中逐项可定位:盲检四成因 = `FF-2`…`FF-5`,`git diff` 三形态 = `FF-6`…`FF-8`。断言 MUST 按这 7 项逐项进行,**MUST NOT 按清单总条数断言**(清单可生长,FR-020)。

**C-15** 反空真哨兵:断言"未点名的失效形态集合为空"时,MUST 同时断言"7 项中至少一项在清单中命中",使"空因为对"与"空因为盲"可区分。

**C-16** fast fail 清单中"仅不可撤销动作方可通过"一条 MUST 以**路径**委托 `shared/guidelines/confirmation-gates.md`,MUST NOT 复制其破坏性动作清单或治理保留清单的任何条目文本。

## 上送件与披露

**C-17** `## 上送件与披露` 节 MUST 含:(a) 四要素的完整枚举;(b) **封闭处置集**的四项取值(`按建议处置` / `改为顺手修复并继续` / `照原样继续` / `终止本次运行`),并声明扩展只经修订本文档;(c) 界面类归属为 **⑪ 失败如实报告**,且 MUST NOT 出现"① 门控确认提示"作为上送件的归属;(d) 干净运行的显式陈述义务,含字面量 [[STR-013]];(e) 以指针(而非复述)引用执行报告的粒度规则。

## 生长闭环

**C-18** `## 生长闭环` 节 MUST 含:(a) 观察标记字面量 [[STR-001]] = `[fast-fail]`;(b) 两条红线——干净运行 MUST NOT 追加空洞观察条目、MUST NOT 编造数值;(c) **双向**生长规则(升级与降级两侧资格对称),MUST NOT 只存在朝停止一侧的通道;(d) 留痕要求;(e) MUST NOT 静默调参的禁令;(f) 以指针引用既有 probe 与自省入口,MUST NOT 声明新增 probe 类/对象或新增自省流程。

**C-19** `## 生长闭环` 节 MUST 载明 SC-015 的三个数(快速失败率 / 用户推翻率 / 清单净生长方向)且 MUST 声明三者由既有存据导出、MUST NOT 新增计数器或台账。

## 标记互斥与中立性

**C-20** 四个稳定字面量——[[STR-001]] `[fast-fail]`、[[STR-009]] `fast-fail-clause`、[[STR-010]] `ANOMALY:`、[[STR-002]] `shared/guidelines/fast-fail.md`——MUST **两两互不为子串**。本条为纯字符串运算,不依赖任何制品存在,故在 red-first 阶段即可断言(FR-063 / V1)。
