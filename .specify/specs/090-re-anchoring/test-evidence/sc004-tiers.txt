## Legitimate asymmetry (named, not smoothed over)

- **Cost figures exist only on side A.** The owner page owns the cost column (`约 1 KB` / `约 5 KB` /
  `按需`); the protocol states triggers and payloads, never bytes. This is the intended division: the
  owner owns the tier table, the protocol owns the procedure (`re-anchoring-definitions.md:5`). A copy
  of the cost column in the protocol would be a second authority for a fact the owner already declares.
- **Side B names the anchor's source per tier, side A names it once.** A says "状态脊的 … 或 agent 的
  分配锚摘要"; B says "the state spine's …" and, for agents, "agent 的规则摘要" appears on side A only.
  Both sides therefore carry the *payload*, and neither adds a tier the other lacks (3 = 3).
