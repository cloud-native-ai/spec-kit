# Contract: Execution Report(执行报告)

**消费方**: 全部改为自动执行的动作所在流程(team 创建/运行/收尾、goal/tools/agents/skills 定义写入、术语写入、反馈记录等)
**溯源**: FR-009、FR-010;澄清会话 2026-08-18(粒度豁免);data-model.md Entity 3

## C-1 三要素

每个作为流程主要产出动作的自动执行动作,完成后 MUST 呈现:

1. **执行内容** — 做了什么;
2. **产出/变更工件** — 落盘或变更对象,逐项可定位;
3. **修改途径** — 既有修订命令或编辑入口。

## C-2 琐碎并入

单个琐碎动作(如自动写入一条术语条目、记录一条反馈)MUST NOT 独立产出完整三要素报告;MUST 并入所属流程的收尾报告,以一行逐项列明(动作 + 对象 + 修改入口)。

## C-3 合并呈现

同一流程内多个自动执行动作 MUST 合并为一次收尾呈现,逐项列出;MUST NOT 逐动作打断用户。

## C-4 失败如实报告

自动执行中途失败 MUST 报告:失败点、原因、已产生的中间产物;MUST NOT 静默跳过、MUST NOT 掩盖部分完成状态。

## C-5 落点形态

执行报告契约 MUST 沉淀于判据文档(confirmation-gates.md)的"执行报告"节,供各命令模板单行引用;各命令模板 MUST NOT 各自重述三要素定义。
