# Contract: Stage-Team Preset and Adapter (ST-01…ST-12)

**Feature**: 070 — Task Decomposition & Team Coordination for Subagent-Driven SDD
**Preset path**: `skills/external/sdd-loop-driver/templates/stage-team-preset.md` (new driver-owned asset).
**Schema compatibility**: `skills/internal/create-team/references/team-presets.md` (field shape only; no catalog registration).

- **ST-01 (Preset location and status)**: The preset lives at the path above. It is not placed in `skills/internal/create-team/templates/teams/`, is not registered in the create-team catalog, and is loaded by the driver adapter by explicit path. `match-team-preset.py`, `create-team`, and `run-team` are not modified.
- **ST-02 (Frontmatter contract)**: The frontmatter carries `preset_id`, `name`, `pattern`, `summary`, `when_to_use`, `signals`, `inputs`, `members`, `config`, and `provenance`, with the field semantics of the existing preset contract. `preset_id` is `sdd-stage-team`. The declared `pattern` is `parallel` as a default shape only.
- **ST-03 (Mandatory body sections)**: The body carries `## Goal Skeleton`, `## Static Structure`, `## Dynamic Structure`, `## Instantiation`, `## Constraints & Hard Rules`, and `## Known Pitfalls`. `Instantiation` states that the projection is run-scoped and explicitly forbids creating a team directory or persisting a team definition.
- **ST-04 (Standard seats)**: The roster defines exactly four seats: `stage-planner` (executor, Worker, persistent), `stage-worker` (executor, Worker, temporary), `stage-verifier` (evaluator, Worker, temporary), and `stage-integrator` (executor, Worker, temporary). Responsibilities are as declared in `notes/clarify-decisions.md` D1.2.
- **ST-05 (Seat-to-execution mapping)**: `stage-planner` is filled by the driver itself (decomposition, gate invocation, scheduling, spine writes). `stage-worker` is filled by one execution per Work Package (native subagent locally; one detached runner remotely). `stage-verifier` is filled by one fresh-context read-only execution per verdict and never by the package executor. `stage-integrator` is filled by one execution per decomposed stage attempt. The driver never dispatches another coordinator.
- **ST-06 (Pattern selection)**: The selected pattern is derived from the graph, never from the preset default: `iteration` when a complete `repair_loop` exists (review repair in the first slice); otherwise `parallel` when two or more packages are independent and every package is read-only; otherwise `serial` (any write package or any dependency edge). A serial stage may still run independent ready read-only packages concurrently under SD-04.
- **ST-07 (Continuous excluded)**: `continuous` is never selected and never appears as an adapter flow. No long-lived team loop is created.
- **ST-08 (Run-scoped adapter)**: The adapter binds the preset and the package graph into the run-scoped plan fence: it substitutes stage, line, plan hash, slot cap, pattern, and the package-to-seat mapping. It creates no team directory, goal binding, or team run report. Each package's `seat` field carries its derived Role × Stage × Type.
- **ST-09 (No persisted team)**: No `.specify/teams/<slug>/team.md` is created per stage, per attempt, or per run. A fixture dry run asserts that no team directory appears.
- **ST-10 (Skills unchanged)**: `create-team` and `run-team` behavior, templates, presets, and run reports are unchanged. The preset is not added to their catalog and no `preset:` reference is added to any persisted team.
- **ST-11 (Provenance)**: The preset's provenance records that its shape derives from the Feature 070 measured baseline and the existing Role × Stage × Type vocabulary, not from a catalog run, and states the first-run evidence obligation (the first decomposed stage's coordination report path is recorded when it closes).
- **ST-12 (Graph over preset)**: The preset's declared default pattern, roster, and slot cap are starting values. The graph-derived pattern, the resolved slot cap, and the per-package seat mapping always take precedence and are recorded in the plan.
