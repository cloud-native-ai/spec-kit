Counting check under the new rule:

    算子级行数 = 1
    passed      = 1   （verdict == pass 的算子级行）

    不参与任何跨级等式：本规格已删除「算子总数 − (passed+failed) = NA 条数」这一条，

## 4. Why the old reading failed on this exact sample (regression witness)

    old rule: 算子总数(1) − (passed(1) + failed(0)) = 0
              expected NA count                          = 1（build 行）
              0 ≠ 1 → 违规

The sample is fully compliant (structure pass, build legitimately not-applicable), so the old rule
produced a **false positive**. The new rule removes the cross-level equation instead of special-casing NA.
