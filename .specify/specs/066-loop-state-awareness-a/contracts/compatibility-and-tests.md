# Contract — Compatibility, Distribution and Tests

**Owner**: this contract names the non-regression obligations for slice A; the owners of the protected surfaces are `scripts/watch-target.sh` / `references/watch-model.md` (watch), `scripts/line-registry.py` (Registry), `references/stage-prompts.md` (U4/spine), `references/efficiency-model.md` §3 (plan artifacts), and `scripts/python/sync-mirrors.py` (mirrors). Clauses are numbered `CMP-NN`.

- **CMP-01**: `scripts/watch-target.sh` MUST NOT change in this slice. The contract suite pins the measured SHA-256 `b6a275dbab62bffafadfb36eb5c389ab27e6f9bf7d498af8102c280201f2b0b4`; any byte change MUST turn the test red. The watcher `--self-test` remains a separate green requirement (measured baseline 38 passed / 0 failed).
- **CMP-02**: The snapshot MUST NOT reuse or redefine watcher exit codes 10–16. Its exit ladder is only 0/1/2, and no `loop_state` is encoded as an exit code.
- **CMP-03**: Registry entry format and `line-registry.py` actions MUST remain compatible. Slice A reads the entry JSON and does not write Registry, lease, reservation or ownership state. Unreadable/invalid entries are reported, never repaired.
- **CMP-04**: `references/stage-prompts.md` MUST NOT change its state-spine write timing or its U4 procedure. The owner reference may cite the U4 artifact list and the stall-default owner; it MUST NOT copy the numeric defaults. The owner reference MUST carry the atomic watchbeat write form and SKILL.md Hard Requirements MUST carry the driver's write obligation (FR-010), and the stage map's plan-owned rows MUST be asserted equal to `efficiency-model.md` §3 and its U4 rows equal to `stage-prompts.md` § Independent Verification.
- **CMP-05**: Two hats: the edit lands in `skills/external/sdd-loop-driver/` and is mirrored to `.specify/skills/sdd-loop-driver/` by `sync-mirrors.py`. The mirror MUST NOT be hand-edited. Baseline before the edit is 26 files, 0 drift; the post-write criterion is zero drift for the pair, with `filecmp` on the new files.
- **CMP-06**: `docs/reference/skills/sdd-loop-driver.md` MUST gain a state-awareness entry that names the snapshot call shape, the relationship to the watcher and Registry, the read-only boundary, and the fact that `recover`/`check-spine` are not available in this slice. The docs page is not mirrored.
- **CMP-07**: The contract and integration suites MUST enumerate and cover these named fixtures in their own sources: `sentinel-with-missing-artifact`, `legacy-spine-snapshot`, `artifacts-without-completion`, `dead-no-exit-record`, `unwatched-vs-window`, `registry-missing`, `registry-present-spine-missing`, `registry-present-spine-missing-with-watcher-verdict`, `not-dispatched`, `probe-snapshot`, `stale-run`, `foreign-carrier`, `deadline-overrun-live`, `heartbeat-stalled`, `accident-replay`, `salvage-two-state`, `implement-commit-missing`, `resume-commit-missing`.
- **CMP-08**: Mutation drills MUST demonstrate that removing each of these behaviors turns at least one named test red: (a) no-watcher detection, (b) completion/`loop_state` separation, (c) interruption-only annotation. The implementation records the three drill commands, the mutated line, the red test name and the restored green result in a dated record. A drill that stays green is a finding, not a pass.
- **CMP-09**: Tests MUST prove determinism (two runs, `evaluated_at` removed, canonical JSON equal) and the no-write boundary (tree hash unchanged for a snapshot without `--out`; only the output path changes with `--out`).
- **CMP-10**: `--self-test` MUST cover: every applicable interruption form; stale/foreign/unattributed contamination; artifacts complete without a sentinel; dead process with no exit record; sentinel with missing artifacts; live `TIMEOUT`; legacy spine; remote-unreachable evidence; `registry.status=missing`/`unreadable`/`invalid`; Registry-present/spine-missing with and without a watcher verdict; not-dispatched; `retry_limit`/`attempt` unknown; probe snapshot; "forms do not override `loop_state`"; foreign carriers do not drive `retry`; and the exit ladder 0/1/2. The recover lock and refusal paths are explicitly not claimed by this slice.
- **CMP-11**: No new runtime dependency, daemon, service, model API or package is introduced. The engine imports only the Python standard library; the only subprocesses are the existing watcher and git, both read-only and bounded.
- **CMP-12**: Slice boundary: `recover`/`check-spine` execution, state-spine writes, recovery records, `attempts/` isolation, recovery locks, handoff files, lifecycle validation and live-process stop decisions are out of scope. The tests and docs MUST NOT claim they are implemented. The later slices add them without changing the snapshot schema's existing fields.
