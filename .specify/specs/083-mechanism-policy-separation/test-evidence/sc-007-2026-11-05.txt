"Exactly one" is read per file, not in aggregate: `source_refs=1` on all five could not
be reached by one file carrying two and another carrying zero — the assertion loops per
path. `mirror_refs=0` on all five is the other half of the same claim: no consumer cites
the generated mirror (`.specify/shared/definitions/…`), which is the coordinate that
would silently freeze a stale copy.

Line numbers are reported for location, never asserted: a line number drifts with any
edit above it, so pinning it would turn an innocent rewrite into a red gate.

## 3. The containment scan — denominators and permitted classes

    scanned=54 skills/**/SKILL.md
    permitted[owner]=0   permitted[owner-mirror]=0   permitted[fixture]=0
    class-name[zero-hit]=0   class-name[out-of-ladder]=0
    class-name[unreadable]=0  class-name[dual-layer]=0

- **Denominator**: every `SKILL.md` under the framework-source `skills/` tree. `find
  skills -name SKILL.md | wc -l` → `54`, identical to `scanned=54` (no `__pycache__`
  files, no mirror copies inside the source tree). The `.specify/skills/**` mirror is
  **not** in this denominator; parity there is proved by `sync-mirrors.py --check`
  (T036, `test-evidence/implement-part5-t036-t037.txt`).
- **Hits**: **zero**, so there is no `hit <path>:<line>` line to report. That is the
  honest form of a zero: the scan prints each hit it finds, and found none.
- **Per-class counts are all 0 and that is expected**: the three permitted classes are
  the owner file, the owner mirror and the fixture directory — none of them is under
  `skills/`, so a permitted hit can only arise if a `SKILL.md` were the owner. Counting
  them separately is what keeps "0 hits" from hiding "the scan never classified
  anything".
- **Two vocabularies are scanned.** The eight step identifiers `NP-1`…`NP-8`; the four
  class names read from `data-model.md` E-10 at call time (and cross-checked against the
  module's own constant, so an edited E-10 fails here rather than widening the search
  silently); and the class **criteria** (`路径落在已知位置之外`, `目录无可读
  \`SKILL.md\``, `两个不同层同名命中`) — the second vocabulary a copy carries, and one
  that already stood in `run-skills` before the T031 rewrite.

## 4. Recomputing this reading

- Re-run § 1. Both halves are deterministic file reads; no model judgement is involved.
- Discriminating power (GM-07), in the same run's `7 passed`: a `tmp_path` copy of

  assertion red; a copy appending `Step NP-3 strips the label.` turns the step-literal

  per-class counts summing to the permitted hit total.

## 5. Disclosure

The containment claim is a **containment** claim and carries its five declarations:
baseline reference object (`3ffeb26e`, used only to locate historical hits, never
asserted against current content), comparison unit (`skills/**/SKILL.md`), allowed
difference set source (three named classes, counted not listed), complement assertion
(zero copies of either vocabulary outside the permitted classes) and the undefined
aggregate-word clause (no "其余 / 未受影响" scope anywhere in the contract). The scan
deliberately counts a class name only in the three forms a copied table takes (table
row's leading cell, definition-list member, bare token), because the bare English word
appears in unrelated prose (`unreadable` as a record status and a page quality); the
criteria scan closes the hole that tightening would otherwise open.
