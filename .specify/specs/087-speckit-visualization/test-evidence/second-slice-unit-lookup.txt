## 4. `run_id` resolution is not a function of the record (measured)

`scripts/python/exec-quant.py` owns run identity through `resolve_run_identity(workspace_root, unit_id,
explicit_run_id)`, which composes the explicit value, an *adopted* adjacent run-determination record inside a
time window around **now**, and a *synthesized* `<slug>-<now>`. There is no per-record resolver: the stored
`run_id` is a snapshot of the writer's resolution at collection time.
