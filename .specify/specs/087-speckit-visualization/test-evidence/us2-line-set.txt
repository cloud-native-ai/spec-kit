triplets, fixture interval 2s) plus the 4 sub-flow rows they carry.

   tick 1 renders `delta=elapsed 0s since run start` under
   `run=r20261106T092000Z-us2l`; a `trigger=boundary` line follows at elapsed 2s;
   tick 2 renders `delta=elapsed 4s since run start` under the same run stamp.
   0s -> 4s across the boundary is the observation that the cadence clock is
   the run's, not the boundary's: a reset would have shown 2s on tick 2.

   marked as emitted before a tick: `trigger=transition:sub-flow failure`,
   `trigger=transition:stall crossing`, `trigger=transition:dispatch failure`,
   each with `class=` and `remainder=reporting … now, not at the next tick`.
   Distinct stamps per class mean a transition is a separate emission, not a
   re-labelled tick. RO-08 pass over the lines set.

   mid-run loss of the live receiver is emitted as
   `trigger=boundary | profile=interactive | switch=live receiver lost (the last
   active line ended); interactive profile from this boundary on`, and the next
   line renders `profile=interactive`. A profile change is therefore always a
   recorded `switch=`, never a silent change of cadence.

   `trigger=reporter-failure` with `blocker=the reporting loop did not emit this
   interval`. RO-11 pass.
