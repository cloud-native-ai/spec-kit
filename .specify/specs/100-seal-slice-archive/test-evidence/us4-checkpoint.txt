## T034 — 单一机制与并发静态审计（C-111 / C-312；FR-020、FR-027、FR-028、SC-005、SC-009）

新增/修订的断言组（`tests/contract/test_seal_boundaries.py`）：

- 外部命令白名单封闭：只读 git 动词 + 唯一 `mv`；`mv` 的两个调用点恰在 `_archive_move`（前向批次）与 `_archive_restore`（按原字节恢复的逆移动）；`push` / `rm` 字面量缺席；注入 `git push`、`git rm`、恢复之外的 `.unlink()`、注册表状态写入、退休归档共享聚合与第二映射表时审计转红。
- 写面以数据表表达（`WRITE_SITE_TABLE`）：`_write_if_changed` / `_archive_write_text` / `_write_seal_batch` / `_archive_restore` 四个宿主之外无写调用；移动仅 `archive-apply` 且目的地由 `_archive_destination_rel` 固定为 `<parent>/slices/<slug>/`。
- 并发夹具 `tests/fixtures/seal-archive/concurrent/`（两个独立父 spec `110-fixture-north` / `120-fixture-south`）：两个归档进程并行执行，各自写入自己父 spec 下的不同清单路径；无锁文件、无租约、无共享聚合；同一 spec 的后到者读清单收敛为 `already-archived` 且零写入，清单缺席而分片全在目的地时以 exit 2 `archive-drift` 拒绝。
- C-312：无缓存引擎 / 派生索引 / 第二份映射表（导入与名字扫描 + JSON 文件名封闭集）；归档树每次动作重新读取——归档目录内注入一个多余文件后，下一次 `archive-plan` 以 exit 2 `archive-drift` 观察该变化。
