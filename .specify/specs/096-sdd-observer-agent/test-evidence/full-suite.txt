## D) Root cause of the two deterministic trigger failures (pre-existing debt)

`test_c18_threshold_priority_chain` asserts the init default is 3, reads 5;
`test_a_single_missed_flow_is_below_the_add_rule_bar` sees an add-rule proposal after one
missed flow. The 5 is the repository-level `.specify/memory/trigger/index.json` value
(unchanged at base and HEAD), not the engine default 3 (`trigger-utils.py`
`THRESHOLD_DEFAULT = 3`). The suite's temp workspaces are not fully isolated from that
repo-level store: the engine store is written during runs (`.`specify/memory/trigger/
index.json` showed up modified after every full run; restored afterwards), so these tests
read a store another run tuned. Both tests fail identically at the base tree — recorded
pre-existing debt, not a 096 regression.
