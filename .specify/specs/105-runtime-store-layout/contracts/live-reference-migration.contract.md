## L-2 Rewrite rules

1. Apply the mapping mechanically to live surfaces (L-3). A mapping is per path token; prose that discusses the *memory system* (not a path) keeps the word "memory" and is edited only to avoid naming a directory.
2. Never run a blind repository-wide substitution: dated records (L-4) are excluded by path.
3. Where a live line's meaning would change (e.g. "the feature registry under `.specify/memory/`" — an already-stale statement), repair to the current authoritative location (`.specify/features/`) and record the repair as `repair-stale`.
4. An explicit legacy test fixture may keep the old literal on purpose; tests are outside SC-006's measured product classes. A migration reader that needs the old root derives it from the declaration's `retired_container` value (L-5); apart from the four allowlisted files, no product file in the measured classes carries the literal.
5. Generated artifacts (mirrors, per-tool command copies, `.specify/instructions.md`) are regenerated from their source, never hand-edited (L-6).

## L-5 SC-006 allowlist (closed, exact)

The retired-root literal `.specify/memory/` (and the bare container literal `.specify/memory` not followed by a path character) may occur only in these files, and only on lines matching the stated context:

| File | Allowed lines | Context |
|---|---|---|
| `shared/definitions/framework-map.md` | exactly the tombstone row | tombstone |
| `shared/declarations/facts/runtime-store-layout.yaml` | the `retired_container` statement key | migration machinery (the retired-root fact's machine owner) |
| `scripts/python/anchor-layout-migrate.py` | lines describing/implementing the legacy anchor layout | migration engine |
| `scripts/python/sanitize-utils.py` | legacy-residue constants and checks (`MATERIAL_ROOTS` legacy rows, `legacy-*` findings, `SELF_EXEMPT_PREFIX` old-form rows if retained) | legacy residue scanner |

The `specify migrate` implementation derives the old root from the declaration's `retired_container` value; it does not spell the literal, so it is not an allowlisted file. This keeps the declared set exact: the four rows above MUST each contain at least one occurrence after the change, and no other file in the framework-source, runtime-guide, or current-docs classes may carry the literal. The guard test (`tests/contract/test_store_layout_live_refs.py`) MUST:

1. compute the occurrence file set per class and assert equality with the declared set (both directions);
2. inside each allowlisted file, assert every matching line satisfies that file's allowed-line rule;
3. assert the allowlist declaration in the test equals this table (the table is the human face; the test literal is the pinned copy);
4. carry a mutation drill: moving the literal into an unlisted line of an allowlisted file, and into one unlisted file, each turns the test red.

SC-006's per-class measurement uses the classes exactly as the requirements state (framework-source / runtime-guide / current-docs), with the L-4 dated-record exclusions.

## L-6 Regeneration and mirrors

- Source → mirror: `sync-mirrors.py` pairs (`templates/`, `skills/external`, `skills/internal`, `agents`, `scripts`, `shared`) and per-tool command copies (`regen-command-copies.py`). Mirrors are regenerated, never hand-edited.
- Baseline measured **before** the change: 450 DIFF members (skills 262 / shared 103 / scripts 65 = 59 plain + 6 projected / agents 20 / templates 0), 0 MISS, 0 ORPHAN; `regen --check` rc 0. The criterion for each touched source is: its mirror is regenerated and the touched-file set carries **no NEW drift member**; scope syncs may also cure pre-existing members, which is recorded as a member-set delta.
- The absolute criterion "both `--check` commands exit 0" is reported honestly against this baseline: the feature's mirror WP converges every scope it touches and records the residual member set. The measured reading and its basis are Decision Tension T-003.
- `regen-command-copies.py --check` requires a typer-capable interpreter; the evidence runs use `/usr/local/bin/python3` (R-10).
