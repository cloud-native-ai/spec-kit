Known limitation, disclosed rather than folded in: a downstream project that runs its own copy of
generate-instructions.sh on a NON-GIT tree aborts at line 65, before any instructions reconcile.
Cause is measured and is not this feature's: common.sh:5 sources ${CWS_LIB_BASH_HOME}/bin/cws_bash_env
on THIS host, whose git_repo_root() falls back to a path derived from the LIBRARY's own location
(/cws_data/cws-lib-bash) and returns '/' in a non-git directory, so .gitignore resolves to
//.gitignore. The same script passes in the T024 evidence because that clone IS a git work tree,
where git_repo_root() returns the real root. Pre-existing defect (recorded in
.specify/memory/feedback/backlog.md, 2026-10-15, M-1), outside this package's write territory.
