# T066 — the incident script rejects an undeclared option, both snapshot files untouched

Clause: C-9 (an undeclared `-*` token exits non-zero before the main action) on the
incident script `scripts/bash/generate-instructions.sh`, plus SC-002's zero-side-effect
limb (`.specify/instructions.md` and `.gitignore` byte-unchanged).
Task: `tasks.md` T066.

## Where this was run, and why

`/var/tmp/pkg4b2b/T066/tree` — a `git archive HEAD` extraction of this repository
(commit `516cb8f2`) with the CURRENT working-tree `scripts/bash/generate-instructions.sh`
copied in. The measured tree is never the tree a probe runs in (C-10, and the incident
this feature remembers is exactly what happens when it is). `/tmp` is `noexec` on this
host; `/var/tmp` is not, and it is one of the sanctioned sandbox roots.

The tree was run twice on purpose:

* **run A — as archived** (no `.git`): `--version` answers `unknown`, which is C-8's
  first-class answer when the bounded upward search finds no repository root. It is
  recorded because it is *also* the case that proves the answer is derived, never a
  literal.
* **run B — the same tree with an empty `git init`** so the bounded search has a root:
  `--version` then answers `generate-instructions.sh 0.0.22`, the value read at run time
  from `pyproject.toml`.

## Verdict

* The rejected-unknown-option limb holds: an undeclared `-*` token exits **2**, prints its
  error on stderr, prints the full usage on stderr, and produces **zero bytes on stdout** —
  it never reaches the reconcile. A recognized flag in the same line does not rescue it
  (`guard` judges every token before answering any flag; asserted by the engine's own
  clause C-9 and by `tests/contract/test_script_interface_contract.py`).
* `-h` and `--help` print the same 440-byte body; `--version` prints exactly one line.
* Neither `.specify/instructions.md` nor `.gitignore` moves, and no backup file is created:
  absence of a write is shown by the digest pair AND by the backup count, not by the
  digests alone (the damaged-copy control in SC-002 records why: two stable digests are
  not sufficient evidence on a file already in steady state).
* Run A's `unknown` is the C-8 no-root answer, not a failure: the exit code stays 0.
