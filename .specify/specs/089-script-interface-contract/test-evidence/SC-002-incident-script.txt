SC-002 — the incident script's flag path is free (T058)
=======================================================

Clause: SC-002 of requirements.md / C-10 and C-11 of
contracts/script-interface-criteria.contract.md. The subject is
`scripts/bash/generate-instructions.sh`: the script whose unguarded `--help` used to rewrite
`.specify/instructions.md` and append to `.gitignore` (the incident this feature remembers).

Where this was run
------------------
`/var/tmp/sc002/tree`, a real `git clone` of this repository at branch
089-script-interface-contract with the post-T057 `scripts/bash/` copied in. C-10 forbids taking
the evidence inside the measured tree: the scripts' own temporary directories would mask or
counterfeit a real write, and the measured tree must not be the thing that gets damaged. The
clone sits under `/var/tmp`, which is not `noexec` on this host (the owner page § 3 requires
this; `/tmp` is `noexec` here and is never used).

What was measured
-----------------
Two things per tree, and BOTH must hold:

  * the two files SC-002 names — `.specify/instructions.md` and `.gitignore` — by sha256;
  * the tree's whole `git status --porcelain`, by sha256 and by line count.

Four invocations were run per tree: `-h`, `--help`, `--version`, `--no-such-flag`.

Three limbs of the answer move, and any ONE of them is enough to call the control red:

  1. SIZE. Every flag returns the whole 5 019-byte / 47-line reconcile log instead of an
     answer. One line is the contract's shape for `--version`; 47 lines is the main action.
  2. THE UNKNOWN OPTION RUNS THE ACTION. `--no-such-flag` exits 0 on the damaged copy — the
     incident's exact shape, where an undeclared token is silently ignored and the write
     happens anyway. C-9's rejection is what the truncation above it buys.
  3. IT WRITES. The `.specify/instructions.md-*` backup count goes from 1 to 5: four more
     backups, one per invocation, because each invocation is a full reconcile.

The `.gitignore` and `.specify/instructions.md` digests happen to be stable on the damaged copy
too — this repository's live `instructions.md` is already in the reconciled steady state, and
the `.gitignore` patterns those runs would append are already present. That is exactly why the
control records a THIRD observable: a snapshot pair that watches only those two files would be
green on a script that plainly runs the main action. Watching bytes alone is not enough, and
this run states that rather than hiding it behind a green.

Conclusion
----------
SC-002 holds on the incident script, and the pair used to judge it discriminates: with the
guard block present nothing changes and every flag answers; with it removed every flag runs
the reconcile, appends a backup per invocation, and lets an undeclared option through at exit
0. The zero-byte-change limb and the unknown-option limb are both shown, on a tree outside the
measured repository.
