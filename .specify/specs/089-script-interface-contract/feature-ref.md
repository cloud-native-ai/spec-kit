## 6. Disclosed Rulings

1. **The rule ships with the framework, not with this repository.** It lands in `templates/constitution-template.md`
   and `templates/instructions-template.md` so a downstream project gets it at `specify init`; landing only the live
   constitution would make it a local patch that the next project never receives (T-003).
2. **Classification is by running the file, not by reading it** (T-001). Source-shape heuristics were measured and
   rejected — `common.sh`, `declaration_reader.py` and the `tests/` corpus each defeat a path/shape rule.
3. **Mirrors are projected by a declared function where two files cannot be byte-equal** (T-002). The alternative
   (hand-edit the mirror) was measured to be erased on the next re-projection, and the alternative (byte-equal
   bridge) was measured to exit 2 because the bridge sat after `if __name__ == "__main__"`.
4. **`unknown` instead of a non-zero exit when `pyproject.toml` is unreachable** — recorded as an assumption in
   `research.md` R4, **not** as a tension record, because it has no positive `expected_sacrifice` and so fails the
   owner's admissibility criteria. See § 7 F-3.
5. **`tests/` is classified file by file**, never exempted as a directory (449 of 737 candidates live there).
6. **No driver gate.** The checker is a script plus a contract test; wiring it into the loop's gate set is
   explicitly out of scope, so the feature cannot brick a run by being wrong.
