## Correction applied before this green reading (disclosed)

The first run of this package reported `1 failed, 8 passed`. The failing node was
`test_c06_the_status_template_keeps_its_action_set_and_adds_no_second_surface`:

```text
E       AssertionError: the action set must stay the closed three, got
        ['collect', 'compile-embeds', 'determine', 'digest', 'guard', 'record', 'report']
tests/contract/test_line_registration_wiring.py:137: AssertionError
```

Root cause (test defect, not a surface defect): `_action_set` scanned the **whole** template with
`--action\s+([a-z][a-z-]*)`, so the machine-generated `## Wrap-up` block (probe engine:
`determine` / `collect` / `record` / `compile-embeds`) was mixed into the status command's own
action set. The node was therefore already failing for the wrong cause during the R-5 red run
(a vacuous red leg). Fix: `_action_set` now reads only the authored body — everything before
`## Wrap-up` — which is the region C-06 speaks about. The surface itself was not changed.

After the fix: `9 passed`, rc 0 (reading above). The `## Wrap-up` block is untouched and still
contains its probe calls.
