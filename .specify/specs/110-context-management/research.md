  (`agents/*.agent.md`, e.g. `agents/structure-adjuster.agent.md:31`) and is materialised into host tool
  directories by `render_agents_for_tool` (`src/specify_cli/__init__.py:648`, reached by
  `specify init` and `specify render-agents`). `scripts/python/project-context-render.py` and
  `project_facts.py` do not exist here; the boundary therefore names the render path (A-3a).
- **Memory recall**: `scripts/python/memory-utils.py --action recall`; its scope value domain is
  `shared/declarations/facts/memory-types.yaml#/statement` (measured: `session`, `knowledge`).

  `.specify/instructions.md` (generated by `scripts/bash/generate-instructions.sh`); the constitution is

- **Declaration layer**: `shared/declarations/contract.yaml` owns `required_fact_keys` (`fact`, `kind`,
  `statement`, `consumers`, `former_carriers`; `note` optional), the five `fact_kinds`
  (`threshold`, `closed-set`, `ordered-operator-table`, `mapping`, `record-schema`) and
  `exit_codes` (`ok: 0`, `finding: 1`, `input-error: 2`). `scripts/python/declaration_reader.py`
  exposes `--action list` / `--action get --fact <slug>` plus in-process `load_fact(repo, slug)`
  (`declaration_reader.py:400`).

**Consequence**: the new mechanism maps onto these carriers as declared rows and pointers; it introduces
no package component, no renderer extension, no second memory path and no second parser.

## R-5 — Ambient section generation and the measured budget headroom

`scripts/bash/generate-instructions.sh` reconciles top-level `##` sections additively into an existing
live file (never modifying or removing existing sections) and always emits
`BUDGET: <size> <budget> <within|over>`; the budget constant is `INSTRUCTIONS_BUDGET_BYTES=40960`
(line 119) and the verdict fires at `size >= budget`. Measured 2026-11-27: `.specify/instructions.md`
is **40,170 B**, so the headroom is `40960 - 1 - 40170 = 789 B`. Section counts:
`grep -c '^## ' .specify/templates/instructions-template.md` → **39**, live `.specify/instructions.md` →
**40** (the live-only `## Recurring Operational Lessons` is pre-existing drift the additive generator
preserves). `tests/contract/test_instructions_section_propagation.py` requires every template
section to exist verbatim in the live file and exercises the additive injection in a second leg.

**Consequence**: the `## Context Management(上下文管理)` section must fit inside ~789 B — it is written in
summary-plus-pointer shape. Per A-10 this line **does not** raise the budget and does **not** trim
existing sections: a section that does not fit is an anomaly to surface, not a silent escalation. The
requirements-stage measurement (`test-evidence/requirements-stage-2026-11-27.md` § 1) is the anchor and
is re-measured at implement.

## R-6 — Script interface and exit-code rules

`shared/definitions/script-interface-definitions.md` requires every functional non-read-only script to
answer `-h` / `--help` / `--version` before any action and to reject an undeclared option non-zero
before any action (including after a bare `--`); read-only scripts are in the recommended/optional set.
The house helper `scripts/python/script_interface_cli.py` supplies the runtime-derived `--version` action
(`VersionAction`, reading the nearest `pyproject.toml`) and the parser conventions; the checker is
`scripts/python/script-interface-check.py`; the exit-code triple `0 ok / 1 finding / 2 input-error` is
`shared/declarations/contract.yaml` `exit_codes`. Measured precedent: `flow-class-check.py --version`
prints `flow-class-check.py 0.0.22` (exit 0).

**Consequence**: `context-audit.py` follows the same flag surface and the same exit-code domain, derives
its version line at run time (`unknown` when no reachable `pyproject.toml`), and writes nothing.

## R-7 — Presence vocabulary and the evidence-state reading

The source's four absence tokens (`absent` / `unreachable` / `empty` / `not-evaluated`) were owned by the
source's dispatch package; **in this repository no framework owner declares them** — `grep -rn
'unreachable' shared/` finds only unrelated prose and `not-evaluated` appears only as a report rendering
marker in `shared/guidelines/reporting-obligations.md` (A-3c). Therefore the presence vocabulary — the
positive token `present` **and** the four absence words — is defined once in the new owner document, and
every other surface cites it (A-8). The consistency reading `Unobserved` still reaches its owner by
pointer: `shared/declarations/facts/evidence-seven-states.yaml#/statement` (measured statement:
`Present`, `Wired`, `Exercised`, `Outcome-supported`, `Missing`, `Unobserved`, `Not applicable`).

**Consequence**: FR-020's five-token vocabulary has exactly one definition site (the owner document);
`Unobserved` is consumed by pointer and is never `present` and never "agreement".
