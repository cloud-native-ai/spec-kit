**Disclosure — a bracketed `grep` form gave a wrong count.** An earlier form of this check,
`LC_ALL=C grep '^- \[ \] CHK' <file> | LC_ALL=C grep -cE '\[(Req §|Gap|...)'`, reported **6**, and the same
pattern under the default locale printed the full row list instead of a count. Both readings were wrong: the
`§` is a UTF-8 multi-byte token inside a byte-oriented (`LC_ALL=C`) matcher, and the alternation was
parenthesised in a form that required a bracket layout only some rows have. The rows themselves were never
the problem — `grep '^- \[ \] CHK' <file> | grep -c 'Req §'` reports **44/44** and is the reproducible form
kept above. The wrong readings stay in this record so a reviewer can reproduce the discrepancy instead of
inheriting a clean story; the Python program is the verdict of record because it is locale-independent.
