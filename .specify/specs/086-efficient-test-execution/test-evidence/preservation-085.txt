## 7. 085 SC-010's status follows that evidence (C-050 — T043's third green point)

T041 edited the four `SC-010_*` lines. The status is **`partial`**, not `pass`, and the gap is named in
one line:

```
SC-010_status=partial
SC-010_value=live SDD run via the 085 temporary Goal/Team: 10 stage wave records (requirements..implement waves 1-4) each with a checkpoint, 8 child lines in real worktrees merged through the integration queue, actual concurrency max 3
SC-010_note=... (full text in § 2 above)

```

Why `partial` and not `pass`: 085 SC-010 asks for the **full** stage chain ending in terminal archival,
and this run has reached implement (11 checkpoints, waves 1–4) with the **review stage still outstanding**
— no `review.md`, no review checkpoint. C-050's rule is that a `pass` needs the whole chain; the chain is
not whole, so the honest value is `partial` with the missing stage named. Restating the 085 requirement:
"the feature ran once" is not evidence, and neither is "ten of eleven stages ran".

The complement is measured too — the M-18 leg shows the same evidence-chain reading go **red** on a
doctored copy that claims `pass` with only requirements/clarify/plan checkpoints present, so the
`partial` here is a decision the check would have contradicted if it were wrong.
