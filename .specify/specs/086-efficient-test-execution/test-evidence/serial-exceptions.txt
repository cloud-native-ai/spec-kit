### Leg A — control: the marker form (C-044 green point)

```
$ env -u PYTHONPATH SPECKIT_PYTHON=<venv>/python bash scripts/bash/run-tests.sh -q tests/contract/test_sdd_loop_driver_skill.py
# test runner exceptions: 1 declared serial test(s)
# test runner: mode=parallel workers=auto dist=load passes=2
24 passed in 1.10s
1 passed, 24 deselected in 26.97s
```

The exception is **enumerated** (1 declared), **excluded** from the parallel pass and **re-run** in the
serial pass (`passes=2`, 26.97 s — the load-free cost the marker was introduced to stop paying under
`-n auto`).

### Leg B — M-17 skip form: the exception disappears from the enumerated set

Mutation: the decorator becomes `@pytest.mark.skip(reason='M-17 skip leg')`.

```
$ ... bash scripts/bash/run-tests.sh -q tests/contract/test_sdd_loop_driver_skill.py
# test runner: mode=parallel workers=auto dist=load passes=1      <- no exception line at all
24 passed, 1 skipped in 1.41s
```

RED as required, and differently from the marker-removal leg: the test is now **skipped inside the
parallel pass**, not excluded-and-re-run. It is not one of the three admissible dispositions (C-045):
a skip removes the test from the evidence rather than relocating it.

### Leg C — marker removal: the same case goes red on the enumeration

Mutation: the `@pytest.mark.serial` line is deleted (body untouched).

```
$ env -u PYTHONPATH <venv>/python -m pytest -m serial --collect-only -q tests/contract/test_sdd_loop_driver_skill.py
no tests collected (25 deselected) in 0.01s                                       EXIT=5

$ ... bash scripts/bash/run-tests.sh -q tests/contract/test_sdd_loop_driver_skill.py
# test runner: mode=parallel workers=auto dist=load passes=1      <- no exception line
25 passed in 29.15s
```

The marker/exception-enumeration case fails (the set is empty where C-044 requires exactly this one
member). The 25 `passed` is **not** a green green: the test ran unexcluded and, in this two-file
selection, happened to finish inside its 60 s budget. Under real suite load it does not — see leg F.

### Leg D — M-17 skip form with an injected failure: the exit code is lost

Mutation: skip decorator **plus** `assert False` as the body's first statement.

```
$ ... bash scripts/bash/run-tests.sh --names-out /tmp/m17-names.txt -q tests/contract/test_sdd_loop_driver_skill.py
EXIT=0
# test runner: mode=parallel workers=auto dist=load passes=1
# failed-name list written: /tmp/m17-names.txt (0 entries) passes=1
24 passed, 1 skipped in 1.12s
```

This is the sharpest statement of why M-17 is inadmissible: the test's own failure is invisible — exit 0,
zero names. A skip would have made the suite look healthier precisely when the self-test broke.

### Leg E — marker form with an injected failure: the exit code and the name are kept

Mutation: the marker is kept and `assert False` is added as the body's first statement.

```
$ ... bash scripts/bash/run-tests.sh --names-out /tmp/mk-names.txt -q tests/contract/test_sdd_loop_driver_skill.py
EXIT=1
# test runner exceptions: 1 declared serial test(s)

1 failed, 24 deselected in 0.04s
names: tests/contract/test_sdd_loop_driver_skill.py::test_c22_watch_target_hook_selftest
```

D against E is the whole C-044 argument: the marker form preserves the name list **and** the exit code;
the skip form preserves neither.
