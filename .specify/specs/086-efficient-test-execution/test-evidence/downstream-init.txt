generated `.specify/memory/constitution.md` is the two-line placeholder
(`This file is a placeholder for the project constitution. … use /speckit.constitution command line to

## Why the reading is taken at the template layer (disclosed, not glossed)

The earlier intent was to grep `.specify/memory/constitution.md` and `.specify/instructions.md` in the
freshly initialised tree. On the real product those two files do not carry authored content at init
time (one is a placeholder, one does not exist), so that grep would have returned zero hits for a
reason unrelated to this feature — it would have measured the initialisation order, not the delivery
of the principle. The substitution is disclosed here rather than reported as a passing grep: the
render-verify proves the **shipped** surfaces carry the pointer set, and `tests/contract/test_test_execution_efficiency.py`
(T031) is the guard that keeps them there. The full render through `/speckit.constitution` /
`/speckit.instructions` is not run in this package — it would spend a stage the package does not own.
