- **How to call**: read the skill and follow its Actions 1–8 — refresh base + section observation snapshot, recovery of content lost to older overwriting runs, project-context analysis, section-by-section convergence through the tolerance band (size-budget routes R1/R2; legacy registry / inline Git-Workflow sections superseded), glossary initialization, validation (heading-set coverage check with per-item attribution), residual report.
- **Outputs**: updated `.specify/instructions.md` (+ backups, symlinks, glossary seed) and a residual report (converged / tolerated / recovered / pending, size outcome, prunable backups).
- **Memory face — existing delegation (unchanged)**: prior-memory recall stays with the native **`memory-recall`** skill (`.specify/skills/internal/memory-recall/SKILL.md`) — invoked before the refresh to retrieve recorded conventions, user preferences, durable decisions, and prior-run outcomes from its stores `.specify/memory/session/` and `.specify/memory/knowledge/`; a recalled user decision is never contradicted without asking the user first.
