## Input Contract

- **输入**：`view [team-slug]`。无 slug = 全团队概览（按 slug 升序）；有 slug = 单团队六组呈现。
- **slug 解析只做精确目录匹配**：`.specify/teams/<slug>/`。近似拼写不模糊命中，按 `team not found`（`[[STR-001]]` 的运行时形态）报告。
- **`--scope` / `--spec-dir`** 跟随 `/speckit.team` 的 Scope 段落；团队档案层无法服务的取值必须显式报告，MUST NOT 静默忽略。
- **`--target` 前置拒绝**：view 携带 `--target` 是模式/参数冲突（`--target` 只属于 run），在调用程序之前拒绝；MUST NOT 改道到 run。

## Workflow

### 1. 一次委派（唯一执行动作）

调用确定性只读程序 `scripts/python/team-view.py`（运行时 `.specify/scripts/python/team-view.py`），参数按输入契约透传（`<team-slug>`、`--scope`、`--spec-dir`、`--repo-root` 由程序自定位）。

- 程序的固定规则提取（定义解析、档案枚举、报告清单、台账聚合、最新报告摘要）是唯一读数来源；本技能 MUST NOT 在散文中重推这些事实。
- 本技能 MUST NOT 调用任何引擎写动作，也 MUST NOT 调用 run 模式的预检聚合读取。
- `--json` 是程序的内部测试面，不是用户格式；本技能不向用户呈现它。

### 2. 逐字完整呈现

把程序的输出**原样**呈现（单团队六组 / 概览 / 错误渲染皆同）：

- **重发规则（re-emission）**：程序 stdout MUST 作为**本会话自己的消息**逐字重发；**工具结果不算呈现**（宿主可能折叠长输出，用户看不到）。MUST NOT 以「已在上方」「见工具输出」「已逐字呈现」代替正文；先发完整输出块，再发降级说明（exit 5 等），说明 MUST NOT 替代、删减或重排六组信息。stdout 是正文；stderr 与错误导航在正文之外。
- MUST NOT 删除、重排或合并任何一组；
- MUST NOT 把缺失态标签（`缺失` / `为空` / `不可读` / `未记录`）替换成 `0`、占位符或推断值；
- 至多追加一行框定语，说明模式（single / overview）与 as-of 指针。

### 3. 错误导航（闭集）

| 程序退出码 | 本技能动作 |
|------------|------------|
| `0` | 呈现输出 |
| `2` | 说明输入错误（未声明选项 / 非法 `--scope` / 多余位置参数）并给出接受形态 `view [team-slug]`；不执行任何模式 |
| `3` | 呈现 `team not found`、可用 slug 有界清单（超过 20 条给省略计数）与 `/speckit.team create` 建议 |
| `4` | 呈现 `定义损坏` 与精确路径，并明确声明「这不是 team not found」；不执行任何模式 |
| `5` | 呈现输出并附降级说明（哪一组因引擎读失败而 `不可读`、原因是什么）；不重试、不编造数据 |

## Constraints（不变量）

- **无条件只读**：一次 view MUST NOT 写任何文件、创建任何目录、派发任何席位或登记任何 run line。程序的读动作只读，本技能不追加任何写步骤。
- **不是 run 预览**：本技能 MUST NOT 运行五查预检、MUST NOT 渲染 `blocked` 判决、MUST NOT 声称团队「可以运行」；它只呈现持久化状态与绑定事实。需要运行判定的读者被指向 `/speckit.team run`。
- **不加第二格式、不加第二存储**：没有用户可读的机读格式、没有缓存 / 快照 / 索引 / 注册表 / 第二团队存储。
- **措辞义务**：标识符（slug、pattern、lifecycle 取值、路径、模式名）保留规范形态；解释用中文；每条错误点名 slug 或路径，并给出下一条命令。
- **边界**：本技能不承载 create / modify / run 语义（分属 `create-team` / `improve-team` / `run-team`），不服务单代理撰写（那是 `/speckit.agents`），也不成为单代理操作入口。
